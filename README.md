# Ravenshaw Free Fire Esports — Registration & Live Scoreboard

Official tournament registration portal and 5-match live scoreboard for **Ravenshaw Free Fire Esports** (**12 Squads • 5 Matches • Placement + Kill Points**).

## Features
- **Squad Registration Portal:** 12 team slots (`Slot #01`–`Slot #12`) with captain details, department, WhatsApp contact, 4 main players (IGN & UID), and an optional 5th substitute.
- **5-Match Score Entry Sheet:** Automatic placement points (`1st: 12`, `2nd: 9`, `3rd: 8`, `4th: 7`, `5th: 6`, `6th: 5`, `7th: 4`, `8th: 3`, `9th: 2`, `10th: 1`, `11th–12th: 0`) and kill points (`+1 per kill`).
- **Live Leaderboard:** Real-time standings sorted by total points, Booyahs, total kills, and final-match placement.
- **Shareable Live Link:** Encodes current squad rosters and match scores directly into the URL hash (`#state=...`) for instant sharing.

## Deployment
- **Vercel:** Import this repository at [vercel.com/new](https://vercel.com/new) with **Framework Preset: Other** and click **Deploy**.
- **GitHub Pages:** Open **Settings → Pages**, set **Branch** to `main` (`/ (root)`), and click **Save**.
